# compassbear-figure-strategy

Claim-first figure planning and audit. This skill does not try to automate pretty figures; it designs figures as arguments.

## Handles

- Main figure planning
- Panel ordering
- Main vs Extended/SI allocation
- Figure captions
- Visual hierarchy and color logic
- Reviewer-risk audits for figures

## What it returns

- figure-level claim
- panel-to-claim map
- main/Extended/SI allocation
- caption draft
- visual hierarchy and reviewer-risk notes

## Typical triggers

figure, panel, graphical abstract, caption, color, layout, 配色, 组图, 机制图

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
