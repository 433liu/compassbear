# Figure Claim Map

## Figure-level claim

Every main figure must be reducible to:

> This figure shows that [claim].

If this cannot be written, split or rebuild the figure.

## Panel categories

- Concept panel
- Workflow panel
- Primary evidence panel
- Mechanistic evidence panel
- Benchmark panel
- Application validation panel
- Model/deployment panel
- Control panel
- Context panel

## Removal test

For every panel ask:

> If this panel is removed, what claim collapses?

If no claim collapses, move the panel to Extended Data/SI or remove it.
