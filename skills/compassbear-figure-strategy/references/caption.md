# Figure Captions

## Caption function

A caption should let the reader understand the claim, metric and context without hunting through Methods.

## Caption pattern

1. One-sentence figure claim.
2. Panel-by-panel description with metric definitions.
3. Key quantitative result where needed.
4. Statistical/sample context when relevant.
5. Boundary if a panel could be overread.

## Avoid

- captions that only repeat axis labels;
- undefined abbreviations;
- missing measurement windows, units or basis;
- causal language for correlation-only panels;
- inconsistent sample names.
