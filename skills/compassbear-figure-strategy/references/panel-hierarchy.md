# Panel Hierarchy

## Recommended visual hierarchy

1. The central evidence panel should be largest or placed in the strongest reading position.
2. Concept/workflow panels should help orientation, not dominate the result.
3. Controls should be visible but not visually louder than primary evidence.
4. Mechanism schematics should summarize evidence, not replace it.
5. Model/deployment panels should define assumptions and scope.

## Main vs Extended/SI

Move to Extended/SI when a panel is:

- repetitive;
- raw data supporting an already summarized claim;
- a parameter sweep;
- a robustness check;
- a reviewer-proof control that slows the main story.
