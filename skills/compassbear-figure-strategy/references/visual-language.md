# Visual Language

## Principles

- Use color to encode scientific categories, not decoration.
- Keep the same object the same color across figures.
- Use high whitespace for conceptual schematics.
- Avoid 3D effects unless spatial geometry is the message.
- Prefer vector-style mechanisms for conceptual clarity.
- Use red/blue or warm/cool carefully; define what the contrast means.

## Accessibility

- Avoid relying only on red–green contrast.
- Use direct labels where possible.
- Keep panel labels large and consistent.
- Make line weights readable after journal scaling.

## Output notes

When advising a figure, return:

- color role table;
- typography notes;
- clutter reduction notes;
- consistency risks with other figures.
