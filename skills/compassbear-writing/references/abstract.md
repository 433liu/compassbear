# Abstract

## Purpose

The abstract should state the problem, material/conceptual gap, approach, strongest results, and bounded implication. It is not a miniature Results section.

## Structure

1. Problem or opportunity
2. Gap
3. What this work reports
4. How it works or was found
5. Most important function/result
6. Bounded implication

## Rules

- Use only the strongest necessary numbers.
- Avoid methods overload unless the method is a core contribution.
- Do not include time, instrument or procedural details unless central.
- Avoid stacking more than three metrics in one sentence.
- Use field-calibrated nouns: proof-of-concept, controlled validation, field validation, deployment scenario.

## AI-rhythm checks

Flag:

- repeated `Here we...` structures;
- triads in consecutive sentences;
- symmetrical mechanism clauses that sound templated;
- abstract endings that overuse `establishes` or `opens new avenues`.
