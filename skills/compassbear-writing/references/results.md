# Results Narrative

## Principle

Results sections should form an evidence ladder, not a chronological lab diary.

## Paragraph pattern

1. Claim sentence
2. Experimental/computational setup only as needed
3. Key result with metric
4. Interpretation
5. Transition or boundary

## Section transitions

Each section should answer why the next section is necessary:

- Discovery → Why this candidate?
- Candidate → Why this mechanism?
- Mechanism → Why this function?
- Function → Why this deployment context?

## Risk flags

- too many sample IDs without narrative;
- mechanism introduced before evidence;
- model results described as truth rather than ranking/projection;
- application result overstated beyond validation setting.
