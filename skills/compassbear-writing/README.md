# compassbear-writing

Drafts, rebuilds and polishes manuscript sections with claim discipline and calibrated scientific voice.

## Handles

- Title
- Abstract
- Introduction
- Results narrative
- Discussion / Conclusion
- AI rhythm / humanization

## Output-first rule

Always return usable text first, followed by a short rationale or audit.

## What it returns

- copy-paste revised prose
- must-fix and nice-to-have notes
- claim/evidence/boundary audit
- propagation notes when numbers or claims changed

## Typical triggers

title, abstract, introduction, results, discussion, conclusion, polish, AI味, senior PI voice, humanize

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
