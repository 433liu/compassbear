# Example — CompassBear Writing

## Scenario

A researcher has a messy draft, figure, response, or decision point and needs `compassbear-writing`.

## CompassBear move

1. Identify the claim.
2. Match evidence to the claim.
3. Remove decoration.
4. Add boundary where needed.

## Output shape

```text
Claim:
Evidence:
Boundary:
Recommended output:
Propagation notes:
```
