# Number Audit

## Extract

- Percentages
- Measurement windows
- Sample sizes
- Concentrations/loadings
- Times and temperatures
- Scale claims
- Model outputs
- Economic metrics
- Biological effects

## Classify

| Type | Example issue | Action |
|---|---|---|
| Contradiction | same metric, different value | fix everywhere |
| Context difference | different time/site/window | define contexts |
| Rounding difference | 22.3% vs 22% | standardize rounding |
| Scope difference | single site vs multi-site max | reconcile explicitly |
| Basis difference | energy vs photon basis | define basis in caption/SI |
