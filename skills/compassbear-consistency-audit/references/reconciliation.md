# Reconciliation Paragraph Pattern

Use when several related but non-identical metrics appear.

```text
Reconciliation of [metric] across the manuscript.

Several related metrics are reported in this work, each chosen to answer a different physical question. To avoid ambiguity, we define them here.

(i) [Metric 1] reports [definition] and is used for [purpose].
(ii) [Metric 2] reports [definition] and is used for [purpose].
(iii) [Metric 3] reports [definition] and is used for [purpose].

The numerical difference among these values arises from [window / basis / time averaging / sample scope / model assumption]. The conservative metric used for [model or claim] is therefore [metric], whereas [larger or context-specific value] is reported only for [demonstration].
```
