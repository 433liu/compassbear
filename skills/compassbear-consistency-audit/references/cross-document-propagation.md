# Cross-document Propagation

When a key claim, number, term, title, figure description, sample name, model assumption or submission metadata changes in one document, silently identify downstream locations that may need updating.

Mention propagation only when inconsistency risk is real.

| Change | Check downstream |
|---|---|
| Title | cover letter, submission system, running header |
| Abstract number | Results, captions, SI, cover letter |
| Figure caption metric | Methods, SI, Abstract if hero number |
| Methods condition | caption, SI, data availability |
| Sample name | all figures/tables, SI, Source Data |
| Journal target | cover letter, formatting, reviewer list |
| Author/affiliation | cover letter, metadata, declarations |
