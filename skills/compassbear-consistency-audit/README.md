# compassbear-consistency-audit

Audits numerical values, terminology, sample names, metric definitions and claim scope across manuscript components.

## What it returns

- inconsistency table
- severity labels
- repair plan
- reconciliation paragraph where needed
- propagation map

## Typical triggers

final check, consistency, 口径统一, 数字检查, metric reconciliation, figure caption audit

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
