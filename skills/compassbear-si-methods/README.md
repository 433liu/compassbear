# compassbear-si-methods

Cleans Methods, Supplementary Information, reproducibility notes and data availability statements.

## What it returns

- Methods structure
- SI audit table
- data availability statement
- reproducibility checklist
- reconciliation section

## Typical triggers

Methods, SI, Supplementary, Data Availability, reproducibility, Extended Data, 方法, 支撑信息

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
