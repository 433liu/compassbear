# Comment Taxonomy

| Type | Meaning |
|---|---|
| Clarity | reviewer does not understand wording or logic |
| Evidence gap | claim lacks support |
| Control missing | missing comparator or validation |
| Mechanism challenge | causality or interpretation questioned |
| Scope/overclaim | claim exceeds evidence |
| Literature/context | prior work missing or misframed |
| Methods/reproducibility | details insufficient |
| Statistical concern | N, variance, test or model issue |
| Impossible request | requested experiment is infeasible or outside scope |
