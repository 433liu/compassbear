# Impossible or Out-of-Scope Requests

## Response pattern

1. Acknowledge value of request.
2. Explain why it is outside scope or infeasible.
3. Add a bounded limitation sentence.
4. Provide available evidence that partially addresses concern.
5. Avoid sounding dismissive.

## Template

```text
We agree that [requested experiment] would provide an additional level of validation. However, [reason] makes it beyond the scope of the present study. We have therefore revised the manuscript to state this boundary explicitly and to avoid claiming [stronger claim]. The current evidence supports [bounded claim] through [available evidence].
```
