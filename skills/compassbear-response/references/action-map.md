# Action Map

| Action | When to use |
|---|---|
| ACCEPT_TEXT | wording unclear; revise text |
| ACCEPT_ANALYSIS | feasible analysis/control strengthens paper |
| SOFTEN_CLAIM | reviewer is right that claim is too strong |
| CLARIFY_SCOPE | claim was intended narrowly; define boundary |
| ADD_LIMITATION | result valid but limitation should be explicit |
| DEFEND_WITH_EVIDENCE | reviewer missed existing evidence |
| AUTHOR_INPUT_NEEDED | data/line/figure info unavailable |
| DECLINE_SCOPE | request is scientifically interesting but outside paper scope |
