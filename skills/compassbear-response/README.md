# compassbear-response

Drafts and audits point-by-point reviewer responses.

The response letter is an editor-facing verification document, not a debate transcript.

## What it returns

- comment taxonomy
- action map
- point-by-point response text
- manuscript-change checklist
- author-input flags

## Typical triggers

rebuttal, reviewer response, revision, reviewer attack, 回防, 审稿意见

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
