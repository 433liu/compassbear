# compassbear-patent

Helps split invention boundaries and draft patent-style claim structures.

Not legal advice. Use with a qualified patent attorney before filing.

## What it returns

- invention boundary map
- independent claim draft
- dependent claim ladder
- embodiment plan
- overlap/risk notes

## Typical triggers

patent, claim, independent claim, dependent claim, embodiment, invention disclosure, 专利, 权利要求, 实施例

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
