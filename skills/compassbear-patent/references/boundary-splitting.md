# Boundary Splitting

When two related patents are planned, define non-overlap explicitly.

| Patent | Independent claim anchor | What to avoid |
|---|---|---|
| Platform/material | material class or synthesis principle | narrow product-only details |
| Product/application | device/composition/use | repeating platform synthesis as core |

## Warning signs

- both patents start with the same independent claim;
- both use the same examples as the only embodiments;
- application claim depends entirely on one material example;
- broad use claims lack technical product features.
