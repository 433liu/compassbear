# CompassBear Research Council

A role-based council for project direction, claim risk and manuscript strategy.

This public version uses anonymous roles only. It does not include private mentor cards, personal rosters or local source notes.

## Roles

- PI Strategist: central direction and journal fit.
- Reviewer Ghost: likely attack paths and missing controls.
- Figure Architect: panel logic and evidence placement.
- Evidence Adjudicator: source status and claim scope.
- Editor: clarity, voice and reader burden.

## Output

Return a council memo with:

- decision;
- strongest argument for the direction;
- strongest objection;
- claim ceiling;
- figure or evidence demand;
- next cheapest action.
