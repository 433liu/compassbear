# Named expert guardrails

This skill may use well-known researchers as broad expertise lenses when the user provides names. It must not impersonate them.

## Allowed

- Refer to a person's public research area.
- Use a named lens to remind the user of likely standards in that field.
- Say "using X only as a public expertise lens".

## Not allowed

- Write as if the real person is speaking.
- Attribute opinions, preferences or private judgments.
- Invent quotations, conflicts, endorsements or likely review decisions.
- Use the person's exact voice or idiosyncratic style.

## Preferred alternative

Convert names into roles:

- "Professor A" -> synthesis-strategy lens
- "Professor B" -> mechanism-evidence lens
- "Professor C" → ML methods lens
- "Professor D" → editor/field-builder lens

This preserves the benefit of expert diversity without false impersonation.
