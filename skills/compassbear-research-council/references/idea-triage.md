# Idea triage

Score each paper idea on five axes from 1 to 5.

| Axis | Question |
|---|---|
| Novelty | What is non-incremental? |
| Evidence | What is already proven? |
| Mechanism | Can the explanation survive attack? |
| Function | Does it work in a relevant setting? |
| Generality | Can others reuse the rule or platform? |

A high-impact paper usually needs at least three strong axes and no fatal weak axis.

If one axis is weak, decide whether to:

- collect evidence;
- demote the claim;
- reframe the paper;
- split into two papers;
- save for follow-up work.
