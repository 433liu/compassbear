# Minimal worked example

## User input

We discovered a new functional material. It has a surprising performance response, a possible mechanism from calculations, and a small prototype demonstration. We are unsure whether to frame the paper as a mechanism paper, a materials-platform paper or an application paper.

## Expected council output

### Decision question

Should the manuscript be led by mechanism, platform or function?

### Synthesis

Lead with materials platform if the material class is general and the device demo is proof-of-function. Use mechanism as the design rule and function as validation. Do not lead with application unless the use-case evidence is mature.

### Next actions

- Build a claim map for Figures 1–4.
- Identify which mechanism claims need causal evidence.
- Move immature application projections to bounded scenario-level language.
