# Boundary Disclosure

A strong cover letter often includes one calibrated limitation sentence. This builds trust and prevents the editor from assuming hype.

## Pattern

```text
We have been deliberate about the boundaries of these claims: [results] are presented as [validated level], not as [stronger unvalidated claim].
```

## Examples

- scenario-level validation, not full deployment proof;
- controlled biological validation, not field-season yield;
- model-guided ranking, not autonomous discovery;
- mechanism consistent with evidence, not complete causal proof.
