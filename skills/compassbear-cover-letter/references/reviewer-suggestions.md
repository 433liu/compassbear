# Reviewer Suggestions

## Reviewer portfolio

For interdisciplinary papers, suggest reviewers covering:

- material/platform expertise;
- mechanism/characterization expertise;
- method/computation/AI expertise;
- application/domain expertise.

## Reason format

```text
(1). Prof. [Name], [Institution], [Country].
Email: [email]
Reason: Expertise in [areas]. Recent representative work includes:
[1] ...
[2] ...
```

## Guardrails

- Do not invent email addresses.
- Avoid close collaborators, recent coauthors and conflicts.
- Prefer active researchers with relevant recent work.
- If a reviewer is only partially relevant, state that honestly.
