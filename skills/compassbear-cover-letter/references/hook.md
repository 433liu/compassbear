# Cover Letter Hook

## Good hook

A good opening tells the editor what changes if the paper is true.

## Avoid

- generic review-style opening;
- long background before the contribution;
- unsupported global claims;
- making an enabling method sound like the only story.

## Hook pattern

```text
[Field need] requires [capability], but [barrier] has prevented [desired outcome]. Here we report [platform/rule/workflow] that [main change].
```
