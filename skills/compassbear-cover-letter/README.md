# compassbear-cover-letter

Builds editor-facing cover letters and reviewer-suggestion rationales.

## Core principle

An editor spends little time on a first-pass letter. Make the hook, why-now, three advances and boundary disclosure visible fast.

## What it returns

- copy-paste cover letter
- three-advance framing
- boundary disclosure
- reviewer suggestion list with reasons
- scope-risk notes

## Typical triggers

cover letter, presubmission, editor, reviewer suggestions, journal fit, 投稿信, 推荐审稿人

## Regression tests

Use the files in `tests/` to check whether the skill still produces output-first, evidence-disciplined answers after edits. Use `examples/` for anonymized worked examples.
