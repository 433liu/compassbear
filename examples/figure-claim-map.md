# Example — Figure Claim Map

## Figure-level claim

This figure shows that the candidate material moves from computational prioritization to application-ready function through a defensible evidence chain.

| Panel | Evidence type | Claim defended | Keep / Move | Risk if removed |
|---|---|---|---|---|
| a | Workflow | Candidate selection was systematic | Keep | Discovery appears cherry-picked |
| b | Structure/record | Candidate identity and observed function | Keep | System feels abstract |
| c | Response profile | Function exists under tested conditions | Keep | Functional claim unsupported |
| d | Mechanism schematic | Proposed rule explains trend | Keep if backed by data | Mechanism feels decorative |
| e | Control | Function exceeds control | Keep | Reviewer attacks baseline |
| f | Application | Relevance beyond bench | Keep/Extended depending maturity | Application claim weakens |
