# compass-bear v0.5.14-public-share

This is a sanitized public-share build of CompassBear Academic Compass.

## What it is

CompassBear is a claim-first research workflow skill for Codex / Claude Code. It helps researchers turn scattered data, mechanisms, figures and applications into defensible scientific manuscripts, proposals, cover letters, rebuttals and patent-style claim structures.

It is not a phrase-polishing tool. The core question is:

> What must the reader believe, and what evidence makes that belief unavoidable?

## Included

- Root `compass-bear` skill.
- Sub-skills for research council, writing, figure strategy, consistency audit, cover letters, reviewer response, SI/methods, patents, PDF reading and WeChat note distillation.
- Public references and examples.
- Local helper scripts for checks, literature RAG, PDF extraction, Zotero handoff and workflow discovery.
- Blank templates under `templates/`.
- Detailed installation guide in `INSTALL.md`.

## Sanitized / not included

- No `.env`.
- No real API keys.
- No generated outputs.
- No personal project rosters or source notes.
- No personal mentor lens cards or related private routing references.
