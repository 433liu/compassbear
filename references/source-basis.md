# Source Basis

CompassBear rules are distilled from repeated high-impact manuscript construction, Nature-family editorial patterns, reviewer-response practice and PI-style claim discipline.

## Rule status labels

- **Hard guardrail** — factuality, no invented data, no unsupported mechanism, no citation fabrication.
- **Strong default** — claim-first figures, boundary disclosure, cross-document consistency.
- **Style preference** — sentence rhythm, phrase choice, visual compactness.
- **Field-dependent** — replication norms, effect-size interpretation, validation maturity.

When applying a rule, identify its status if the user is deciding whether to follow it.
