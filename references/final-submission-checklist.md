# Final Submission Checklist

## Manuscript

- [ ] Title matches central claim and does not over-narrow the platform.
- [ ] Abstract contains only strongest necessary numbers.
- [ ] Introduction defines the gap without over-listing weaknesses.
- [ ] Each Results section has one dominant claim.
- [ ] Mechanistic claims are matched by mechanism-grade evidence.
- [ ] Conclusion states platform/rule/boundary without hype.

## Figures

- [ ] Every main figure passes claim/evidence/removal tests.
- [ ] Captions define metrics and context, not just labels.
- [ ] Panel labels, colors and sample names are consistent.
- [ ] Extended Data/SI receive repetitive validation and raw data.

## Methods and SI

- [ ] Methods are reproducible without becoming the main story.
- [ ] SI reconciles related metrics and assumptions.
- [ ] Data/code availability matches actual access route.
- [ ] Table numbers, figure numbers and section references are clean.

## Submission package

- [ ] Cover letter has hook, why-now, advances and boundary disclosure.
- [ ] Reviewer suggestions cover material, mechanism, method and application where relevant.
- [ ] Competing interests and patent disclosures are consistent.
- [ ] Cross-document propagation has been considered after the final edit.
