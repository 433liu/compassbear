# Public Release Boundary

The public package contains reusable workflow logic only.

## Public

- claim-first workflow rules;
- anonymous role-based research council protocols;
- synthetic examples and eval prompts;
- generic journal-positioning and figure-strategy guidance;
- install instructions without local paths.

## Keep Private

- API keys and environment files;
- local project rosters;
- personal expert cards;
- unpublished manuscript details;
- source notes from papers;
- generated outputs;
- local reference-manager databases or PDFs;
- user-specific preferences.

## Release Check

Before publishing, scan for local paths, private names, hidden project hints, old package names, logs, caches and generated outputs. If a file is useful but private, replace it with a synthetic template or generic protocol.
